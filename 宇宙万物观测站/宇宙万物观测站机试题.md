# 宇宙万物观测站

**120 分钟，从零构建一个完整系统。允许使用 AI。**

## 我们想要什么

我们想建一座宇宙万物观测站。

观测网络不断发现星体、生物、航行器、外星智慧生命，以及从未见过的事物。数据持续涌入，这个世界也在不断变化。

希望你让这些海量、陌生、变化中的对象变得可以被组织、理解和探索。我们希望通过一个直观的用户界面和可视化，走进这个世界，看清其中有什么、正在发生什么。

我们也希望它是一套能在单机上挑战性能极限的系统：容纳足够大的世界，承受足够猛烈的数据涌入，同时保持数据可信、运行可靠、操作流畅。

具体做成什么样，由你决定。请用一个实际运行的作品，展示你对这个目标的理解，以及将它变成现实的工程能力。

## 已有条件

出题方提供对象发生器及[启动与控制说明](发生器操作说明.md)。数据格式不预先提供，由你自行探索。

技术方案自由选择。允许使用 AI 参与整个过程，你需要理解并能够解释自己的交付。

统一验收环境为 Mac 上的 Docker Desktop，运行 Linux arm64 容器。系统全部后台服务合计可使用 **4 vCPU、4 GiB 内存和 20 GiB 持久化空间**；发生器单独使用 1 vCPU、256 MiB。浏览器不计入后台预算。

## 交付

提交可访问的 Git 仓库和最终 commit SHA，包含源码、容器运行配置，以及足以复现作品的 README。说明实际测试结果、关键取舍和已知限制。

我们关注作品的完整性、数据的正确性、系统的性能与可靠性，以及你面对未知问题时的判断和解决能力。
