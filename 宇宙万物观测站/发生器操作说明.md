# 发生器操作说明

本文件仅说明发生器的启动与控制。接收地址由你指定，发送内容的结构不预先说明。

## 启动

在发题包目录执行：

```sh
docker load -i flightgen-image.tar
mkdir -p generator-runs
docker run -d --name object-source \
  --cpuset-cpus=0 --cpus=1 --memory=256m --memory-swap=256m \
  -p 127.0.0.1:9001:9001 \
  -v "$PWD/generator-runs:/runs" \
  talkingdata/flightgen:exam-v4-f1
```

以下命令中的 `target_url` 换成你的接收地址。`host.docker.internal` 表示 Mac 宿主机；接收服务需监听可从容器访问的地址，容器内的接收服务需发布相应端口。

```sh
curl -fsS http://127.0.0.1:9001/start \
  -H 'Content-Type: application/json' \
  -d '{
    "workload": "objects",
    "target_url": "http://host.docker.internal:8000/ingest",
    "test_id": "run-001",
    "seed": 42,
    "batch_size": 20,
    "workers": 4,
    "objects_per_second": 200,
    "rate_profile": "bursty",
    "ramp_seconds": 10,
    "duration_seconds": 120,
    "max_batches": 20000,
    "retries": 2,
    "objects": {"scenario": "evolving", "tree_every_batches": 10}
  }'
```

这里的 JSON 是发生器控制参数。每轮使用新的 `test_id`。`objects_per_second` 是目标平均速率，实际发送会波动；启动后的均值在 `ramp_seconds` 指定的时间内从零爬升。`duration_seconds` 控制本轮时长。运行中再次启动返回 409。

## 查看状态与调速

```sh
curl -fsS http://127.0.0.1:9001/status

curl -fsS http://127.0.0.1:9001/rate \
  -H 'Content-Type: application/json' \
  -d '{"objects_per_second":20000}'
```

速率值 `0` 表示尽力发送，不是暂停。

## 停止与运行记录

```sh
curl -fsS -X POST http://127.0.0.1:9001/stop
curl -fsS http://127.0.0.1:9001/status
```

停止请求返回 202，收尾在后台完成。状态响应外层的 `state` 为 `finished` 后，可以取得运行记录；尚未结束时返回 409。

```sh
curl -fsS http://127.0.0.1:9001/receipt -o run-001-receipt.json
```

关闭发生器容器：

```sh
docker stop object-source
docker rm object-source
```

## 接入约定

发生器向 `target_url` 发送 HTTP POST。接收端返回任意 2xx，表示已可靠保存整条消息；响应正文不作要求。部分发送依赖前序确认。非 2xx 或请求超时表示发生器未获得成功确认，并可能重试。
